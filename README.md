# FormWise AI

Privacy-first AI-assisted form filling. The repository currently includes **Milestone 1: Authentication & User Foundation**: Google sign-in, server-side Firebase token verification, and automatic Firestore user provisioning. No document, OCR, AI, or conversation functionality is included.

See [Development setup](docs/DEVELOPMENT_SETUP.md), [project structure](docs/PROJECT_STRUCTURE.md), [architecture](docs/ARCHITECTURE.md), and the frozen [SDD](docs/SOFTWARE_DESIGN_DOCUMENT.md).
